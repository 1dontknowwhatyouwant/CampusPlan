# CampusPlan Frontend

계획서에 정의된 Next.js, React, Tailwind CSS 기반 사용자 화면입니다.

## 기술 버전

- Node.js 24.x (로컬 확인 버전: 24.14.0)
- Next.js 16.4.6
- React / React DOM 19.3.0
- Tailwind CSS 4.3.3
- TypeScript 5.x

정확한 의존성 버전은 `package-lock.json`으로 고정합니다.

## 설치 및 실행

```bash
npm ci
npm run dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 실행됩니다.
